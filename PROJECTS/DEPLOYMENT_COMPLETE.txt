================================================================================
  TROUBLESHOOTING
================================================================================

Monitor not detecting files?
  → Check folder permissions: data/som-in/
  → Verify .xlsx extension on Excel file
  → Check monitor log for errors

Email not sending?
  → Run: python ops\test_email.py
  → Verify .env has correct credentials
  → Confirm app-specific password (not regular password)

Dashboard not accessible?
  → Verify running: Get-Process python
  → Check port: netstat -an | findstr 5000
  → Try: http://127.0.0.1:5000

Pipeline won't start?
  → Check monitor_service.log
  → Verify previous run completed
  → Check disk space (need 10+ GB)
  → Verify network connectivity
